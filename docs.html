Local AI Server (Termux / Any Device)

To use AI features, you need to run a local AI server on your device. This can be done on Android via Termux, on Linux, macOS, or even Windows.

📱 On Termux (Android)

1. Install Termux and dependencies.
2. Clone and compile llama.cpp.
3. Download a model (e.g., TinyLlama).
4. Run the Flask proxy.
Full guide →

💻 On Linux/macOS

Use the same llama.cpp + Flask setup. You can also run the build service for APK exports.

The AI server runs on localhost:8000 and communicates with the frontend. You can use any GGUF model – just place it in the models directory.

🚀 Quick Start

  1. Start your local AI server (see section above).
  2. Open the Builder – a blank project is auto‑created.
  3. Use the file explorer to add new files (right‑click or use the + button).
  4. Edit code in the Monaco editor with syntax highlighting.
  5. Click the Run button to refresh the live preview.
  6. Ask the AI Assistant (brain icon) for help – it uses your local model.
  7. Export your project as a ZIP or try APK (requires build service).

🎯 Key Features

  • Local AI: Models run on your device (llama.cpp, TinyLlama).
  • VS Code‑like IDE: File explorer, resizable panels, mobile tabs.
  • Project Docs: Store ideas, structure, and notes; AI can use them as context.
  • Auto‑backup: Every 60 seconds, with restore from backup manager.
  • Multi‑export: ZIP, APK, GitHub (coming), Vercel (coming).
