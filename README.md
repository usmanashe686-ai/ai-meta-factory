# 🏭 AI Meta Factory

A full-stack AI development platform that generates complete applications with AI.

## 🚀 Features

- **🧠 AI Component Generator**: Structured idea → code pipeline
- **🏭 Full-Stack Factory**: Complete project generation
- **🗄️ Database Integration**: Supabase, Firebase, MongoDB, PlanetScale
- **🔗 Git Integration**: GitHub, GitLab, Bitbucket ready
- **🚀 Deployment Ready**: Vercel, Netlify, Railway, Render, Firebase
- **📦 Project Export**: ZIP download with full structure

## 🏗️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **AI**: Gemini 1.5 Flash (required) + OpenAI GPT-4o Mini (optional)
- **Deployment**: Vercel
