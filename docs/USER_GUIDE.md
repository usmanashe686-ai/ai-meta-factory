# AI Meta Factory - User Guide

## 🚀 Getting Started

### 1. Creating Your First Project
1. Click "New Project" in the dashboard
2. Choose a template or start from scratch
3. Name your project and add a description
4. Click "Create Project"

### 2. Building Your AI App
- **Drag & Drop Components**: Add UI components from the sidebar
- **Configure Properties**: Click any component to edit its properties
- **Arrange Layout**: Drag components to position them
- **Preview**: Click the eye icon to preview your app

## 👥 Team Collaboration

### Creating a Team
1. Click "Teams" in the sidebar
2. Click "New Team"
3. Enter team name and description
4. Set default permissions

### Inviting Team Members
1. Open your team
2. Click "Invite Members"
3. Enter email addresses
4. Choose permission level (Viewer, Editor, Admin)
5. Click "Send Invitations"

### Real-time Collaboration
- **Live Cursors**: See where team members are working
- **Component Locking**: Automatically prevents edit conflicts
- **Chat**: Communicate in real-time with your team
- **Version History**: Track all changes with ability to revert

## 📤 Project Sharing

### Public Sharing
1. Open your project
2. Click "Share" in the top right
3. Choose "Public Link"
4. Set permission level (View/Edit/Comment)
5. Copy and share the link

### Team Sharing
1. Open your project
2. Click "Share"
3. Select "Team"
4. Choose which team members can access
5. Set individual permissions

### Password Protection
1. When creating a share link
2. Enable "Password Protection"
3. Set a secure password
4. Share both link and password

## 💾 Saving & Version Control

### Auto-save
- Projects auto-save every 30 seconds
- Manual save with Ctrl+S (Cmd+S on Mac)
- Status indicator shows last save time

### Version History
1. Click "History" in the project header
2. Browse through all saved versions
3. Click any version to preview
4. Click "Restore" to revert to that version

### Export/Import
- **Export**: Click "Export" → Choose format (JSON/HTML)
- **Import**: Click "Import" → Select project file

## 🎨 Templates

### Using Templates
1. Go to "Template Gallery"
2. Browse categories or search
3. Click "Use Template" on any template
4. Customize for your needs

### Creating Templates
1. Build your project
2. Click "Save as Template"
3. Add name, description, and category
4. Choose visibility (Public/Private)

## 🔒 Permissions & Security

### User Roles
- **Owner**: Full control, can delete project/team
- **Admin**: Can manage members and settings
- **Editor**: Can edit project content
- **Viewer**: Can only view, no edits
- **Guest**: Limited access, no downloads

### Security Features
- End-to-end encryption for sensitive data
- Password-protected sharing links
- Session timeout after 24 hours
- Two-factor authentication (optional)
- Activity logs for audit trails

## 🆘 Troubleshooting

### Common Issues

#### "Can't save project"
- Check internet connection
- Clear browser cache
- Try manual save (Ctrl+S)
- Export as backup before troubleshooting

#### "Collaborator cursors not showing"
- Ensure all users are connected to internet
- Refresh the page
- Check WebSocket connection status

#### "Component not loading"
- Clear component cache in settings
- Try different browser
- Contact support if issue persists

### Performance Tips
- Limit projects to 50 components for optimal performance
- Use templates for frequently used layouts
- Archive old projects you're not actively using
- Use the desktop app for large projects
